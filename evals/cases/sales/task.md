# 退款后的销售额（模拟业务练习）

用户需求：销售汇总和 CSV 导出都应该计算“已支付原金额减累计退款”，取消订单不计入。现在结果只包含原金额，请修好两个入口，保证业务口径一致。

## 输入与接口

- `app.py` 提供 `summarize_sales(orders) -> int` 和 `export_sales_csv(orders) -> str`。
- `orders` 是字典列表，每条必须有 `status`、`amount_cents`、`refund_cents`。不需要支持迭代器、数据库、HTTP 或文件读写。
- `status` 只允许 `paid` 或 `cancelled`；金额均为整数分，不能是布尔值、小数或字符串。要求 `0 <= refund_cents <= amount_cents`。
- 任意订单字段缺失、状态错误或金额不合法，两个入口都抛出 `ValueError`，不能返回部分合计；取消订单也要检查输入。
- CSV 是两行：表头 `sales_cents`，随后为一行整数合计。用标准 CSV 格式，行尾格式不限。
- 空订单列表合计为 `0`；全额退款的已支付订单贡献为 `0`；不得修改输入。

例如：已支付 `10000` 分、退款 `2000` 分，加上已支付 `5000` 分、退款 `0` 分，结果是 `13000` 分。再加入任意合法取消订单，结果不变。

此练习只使用 Python 标准库，不引入框架或新依赖。
